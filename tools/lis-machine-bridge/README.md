# DigitLab LIS Analyzer Machine Interfacing Bridge (LIS Agent & Simulator)

इस मॉड्यूल के ज़रिये आपकी ब्लड टेस्ट मशीनें (Mindray, Sysmex, Erba, Horiba आदि) सीधे सॉफ्टवेयर से जुड़ जाती हैं और **Zero Manual Typing** के साथ टेस्ट रिज़ल्ट ऑटोमैटिक मरीज़ की रिपोर्ट में भर जाते हैं।

---

## 📁 इस फोल्डर में क्या-क्या है?

| फ़ाइल | विवरण |
| :--- | :--- |
| **`lis_agent.js`** | **Desktop Sync Agent (LIS Bridge)** — यह लैब के कंप्यूटर पर चलता है। यह पोर्ट `5100` पर मशीन से डेटा रिसीव करता है और आपके क्लाउड सर्वर पर भेजता है। |
| **`machine_simulator.js`** | **Blood Analyzer Simulator** — अगर आपके पास असली मशीन नहीं है, तो यह स्क्रिप्ट असली Mindray BC-5000 मशीन बनकर टेस्ट डेटा भेजती है। |
| **`agent_config.json`** | क्लाइंट/लैब की सेटिंग्स (Cloud Server URL, Lab Code, API Key, Listening Port)। |
| **`run_agent.bat`** | विंडोज पर एजेंट को 1-क्लिक में शुरू करने की फ़ाइल। |
| **`run_simulator.bat`** | 1-क्लिक में टेस्ट सिमुलेशन चलाने की फ़ाइल। |

---

## 🚀 बिना मशीन के 10 सेकंड में कैसे टेस्ट करें? (Local Testing Guide)

### तरीका 1: कमांड लाइन द्वारा (ASTM Protocol Socket Test)

1. **Step 1:** अपना बैकएंड सर्वर चालू करें:
   ```bash
   dotnet run --project backend/src/Lab.Api
   ```

2. **Step 2:** पहले टर्मिनल में **LIS Agent** शुरू करें:
   ```bash
   node tools/lis-machine-bridge/lis_agent.js
   ```
   *(या सीधे `run_agent.bat` पर डबल-क्लिक करें)*
   > यह स्क्रीन पर दिखाएगा: `📡 Listening for Analyzer on Port : 5100`

3. **Step 3:** दूसरे टर्मिनल में **Machine Simulator** चलाएं:
   ```bash
   node tools/lis-machine-bridge/machine_simulator.js 2600381 normal
   ```
   *(यहाँ `2600381` आपके सैंपल का बारकोड है)*

   **उपलब्ध टेस्ट प्रीसेट्स:**
   - `normal` — सामान्य CBC रिपोर्ट (Hb 14.2, WBC 7400, PLT 2.45L)
   - `anemia` — गंभीर एनीमिया (Hb 5.2 — Critical Panic Alert)
   - `infection` — हाई इन्फेक्शन / सेप्सिस (WBC 28,500)
   - `platelet_low` — डेंगू / लो प्लेटलेट (PLT 18,000 — Panic Alert)

4. **जादू देखें:**
   - सिम्युलेटर ASTM प्रोटोकॉल से फ्रेम भेजेगा।
   - LIS Agent उसे रिसीव करके क्लाउड API पर पोस्ट करेगा।
   - सॉफ्टवेयर के डैशबोर्ड में मरीज़ की रिपोर्ट में सभी 13 पैरामीटर्स (Hb, WBC, RBC, PLT आदि) ऑटोमैटिक भर जाएंगे और स्टेटस `Completed` हो जाएगा!

---

### तरीका 2: वेब ब्राउज़र से 1-क्लिक टेस्ट (UI Direct Sync)

1. वेब पोर्टल में लॉगिन करें और किसी भी केस के **"Enter Results"** पेज पर जाएँ।
2. ऊपर दाएँ कोने में नया बैंगनी रंग का बटन दिखेगा: **`Machine Sync`**।
3. उस पर क्लिक करें — एक पॉपअप खुलेगा जिसमें उस सैंपल का बारकोड दिखेगा।
4. **"Normal CBC"** या **"Severe Anemia"** बटन पर क्लिक करें।
5. **तुरंत स्क्रीन पर सभी टेस्ट वैल्यूज भर जाएंगी** और हाई/लो फ्लैग्स ऑटोमैटिक कैलकुलेट हो जाएंगे!

## 🏥 असली मशीन को कैसे कनेक्ट करें? (Physical Machine Connection)

जब आपके या आपके क्लाइंट के पास असली एनालाइज़र मशीन आ जाए:

1. **केबल कनेक्शन:**
   - मशीन के पीछे LAN (Ethernet RJ-45) केबल लगाएं और उसे लैब के लोकल राउटर या स्विच में जोड़ें।
   - (अगर मशीन RS-232 Serial वाली है, तो Serial-to-USB कनवर्टर लगाकर कंप्यूटर के USB पोर्ट में लगाएं)।

2. **मशीन की स्क्रीन पर सेटिंग:**
   - मेनू में **Settings > Communication > LIS Setup** में जाएँ।
   - **Protocol:** `ASTM-1394` (या HL7) चुनें।
   - **Target IP:** उस कंप्यूटर का लोकल IP डालें जिस पर `lis_agent.js` चल रहा है (जैसे `192.168.1.100`)।
   - **Target Port:** `5100` सेट करें।
   - **Auto Send / Transmission:** `ON` करें।

3. बस! अब जब भी मशीन में टेस्ट खत्म होगा, डेटा बिना किसी कीबोर्ड टाइपिंग के सीधे कंप्यूटर और सॉफ्टवेयर में आ जाएगा।
